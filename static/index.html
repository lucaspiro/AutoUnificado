⚙️ Cómo funciona

Escribí el sketch completo (con setup() y loop()). El mismo código anda acá y en el Arduino UNO R4 WiFi con WiFiS3.h.
📡 El simulador entiende:
server.available() — te entrega el request HTTP recibido
analogWrite(IN1..IN4, pwm) — mueve las ruedas
pulseIn(echo, HIGH, t) — distancia ultrasónica
analogRead(A0..) — sensor infrarrojo (0–1023)
Serial.print() · millis() · delay()
🔌 Pines: los #define/const de motores y sensores tienen que coincidir con la pestaña ⚙️ Config.
🎮 Mandá comandos HTTP al auto. Flechas o joystick — cambia lo que se envía. Editá las rutas para que coincidan con tu sketch.
⚙️ Pines y nombres de tu auto. Se guarda en config/config.json — exportalo para llevarlo a otra compu.
